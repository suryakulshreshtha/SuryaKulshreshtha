### 🧪 Featured Project



**[Forkable Playwright Self-Healer](https://github.com/suryakulshreshtha/ForkablePlaywrightSelfHealer)** Self-healing Playwright tests driven by plain English. The same spec passes before and after a UI refactor that deletes every `data-testid` and renames every id — locators re-bind at run time and the repair is remembered. Heuristic-first with an optional local LLM (Ollama + RAG), runs fully offline, 125 tests.

**[Playwright Python Pytest Framework](https://github.com/suryakulshreshtha/ForkablePythonProjectShowcase)** End-to-end test automation framework — UI + API testing, network mocking, Page Object Model, data-driven tests, Docker, and GitHub Actions CI. Built with Playwright, Python, and Pytest.
